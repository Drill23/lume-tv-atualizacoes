# Lume TV Player

**Lume TV** é um **player de vídeo (reprodutor de mídia) e organizador de catálogos** multiplataforma desenvolvido pelo **Demerzel Studio**.

🌐 **Site oficial e downloads:** [https://drill23.github.io/lume-tv/](https://drill23.github.io/lume-tv/)

## Sobre o aplicativo

- Reprodutor de mídia com interface *Liquid Glass* para **Android, Android TV, Fire TV Stick, Windows (7 ao 11) e iPhone (iOS)**.
- Organização visual de catálogos de filmes, séries, animes, desenhos e listas M3U / EPG acessados pelo usuário.
- Preferência de áudio em português do Brasil, Smart Auto-Sub, sincronia de legenda (`±0,5 s`), perfis com PIN, Modo Infantil e Player YouTube integrado.

## Acesso

Para ativar e sincronizar seus perfis e listas no player, utilize o código de ativação informado no site oficial.
